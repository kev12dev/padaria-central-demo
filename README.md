# Padaria Central de Barueri — demonstração independente

Este projeto é uma proposta visual e **não é o site oficial da Padaria Central**.

Arquivos: `index.html`, `style.css`, `script.js` e `assets/`.

## Publicar pelo GitHub Pages
1. Envie os arquivos para a raiz de um repositório público.
2. Abra Settings > Pages.
3. Em Build and deployment, selecione Deploy from a branch, branch `main`, pasta `/(root)` e salve.
4. Aguarde a publicação.

## Antes de usar comercialmente
- Confirme com a empresa os telefones, e-mail, endereço, horários e canais de delivery.
- Solicite autorização para uso da marca, fotos e história.
- Troque as imagens ilustrativas por fotos autorizadas.
- Confirme produtos, preços e disponibilidade.
- As imagens atuais usam URLs externas e precisam de internet.
- Os botões de cardápio ainda levam à seção de contato porque o catálogo detalhado não foi fornecido.
